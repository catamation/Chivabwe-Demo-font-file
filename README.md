# Chivabwe Demo Font File

This repository contains a demo font file for the Chivabwe writing system.

⚠️ This project is still a work in progress and is not yet fully completed or fully up to date.

The repository is being made public early so people can:
- view the development progress
- experiment with the font
- provide feedback
- follow the project as it evolves

Please expect:
- unfinished characters
- missing features
- inconsistencies
- future changes and updates

## About Chivabwe

Chivabwe is a newly developed writing system designed for Bantu languages.
